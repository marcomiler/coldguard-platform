# Eventos

- AssetRegistered
- TelemetryReceived
- TelemetryThresholdBreached
- IncidentCreated
- IncidentAcknowledged
- IncidentEscalated
- IncidentResolved
- IncidentClosed
- NotificationRequested
- NotificationFailed

`IncidentAcknowledged` se emite al atender el incidente (CU-004, detiene el reloj de reconocimiento de RN-006).
`IncidentClosed` se emite al cerrar el incidente con causa y comentario de resolución (CU-006, RN-007).
